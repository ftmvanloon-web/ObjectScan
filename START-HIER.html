iPhone 16 Pro + Windows · startproject

Je eigen objectscanner.

Een iPhone-app die foto’s en LiDAR combineert tot een 3D-model. Je scans worden op de iPhone verwerkt en zijn vrij te exporteren.

Broncode op GitHub → Cloudbuild → AltStore op iPhone

De status van dit pakket

De eerste broncode en de buildworkflow zijn voorbereid. De syntaxis en projectstructuur zijn gecontroleerd. Er is nog geen Xcode-build uitgevoerd en er is nog geen scan getest op een echte iPhone.

Dit ZIP-bestand bevat dus het project. Het installeerbare .ipa-bestand ontstaat bij stap 2. Een eigen Mac is daarvoor niet nodig.

Wat deze versie doet

De app herkent het object, toont een aanpasbaar kader en begeleidt je terwijl je eromheen loopt. Daarna maakt Apples Object Capture op de iPhone een model met vorm en textuur. Je krijgt een lokale bibliotheek, 3D-voorvertoning en export via het iOS-deelmenu.

Het directe exportformaat is USDZ. Op Windows kun je dat in Blender openen en verder omzetten naar OBJ of STL. De methode is fotogrammetrie met LiDAR-ondersteuning. Apple: Object Capture

De cloud is alleen nodig om de app te bouwen. Je scanbeelden gaan vanuit deze app niet naar GitHub of een verwerkingsserver.

Wat kost de route?

Een gratis Apple-account volstaat voor de installatie met AltStore Classic. De standaard GitHub Actions-runner is gratis bij een openbare repository; daarmee wordt de broncode openbaar. Bij een privérepository wordt je inbegrepen maandtegoed gebruikt en kan extra gebruik kosten meebrengen. GitHub: inbegrepen gebruik

Met het gratis Apple-account moet je de app uiterlijk elke zeven dagen vernieuwen via AltStore en je Windows-pc. Dat vraagt geen nieuwe cloudbuild. AltStore: vernieuwen

1Zet het project op GitHub

  1. Pak het broncodepakket op je Windows-pc uit. Staat het project al in jouw GitHub-repository, ga dan direct naar stap 2.
  2. Open github.com/new, log in of maak een gratis account en maak een repository met de naam ObjectScan. Kies de zichtbaarheid die bij je past; zie de kosten hierboven.
  3. Kies uploading an existing file of Add file → Upload files.
  4. Open op je pc de uitgepakte map ObjectScan en sleep alle bestanden en mappen binnen die map naar GitHub. Upload de inhoud, dus niet het ZIP-bestand zelf.
  5. Controleer dat .github, ObjectScan.xcodeproj, ObjectScan en scripts direct op het hoogste niveau staan. Klik op Commit changes.

De verborgen naam .github is essentieel: die map bevat de cloudbuild. Er staan geen wachtwoorden of sleutels in dit pakket.

2Maak het iPhone-installatiebestand

  1. Open het tabblad Actions in je repository.
  2. Kies links Build ObjectScan for iPhone.
  3. Bij de eerste upload van de app start al een build. Je kunt ook met Run workflow een nieuwe build starten op je standaardbranch.
  4. Open de nieuwe run en wacht op een groen resultaat.
  5. Download onder Artifacts het bestand ObjectScan-iPhone. Pak ook die ZIP uit. Daarin zit ObjectScan-unsigned.ipa.

Het bestand blijft zeven dagen beschikbaar. De workflow heeft geen Apple-inloggegevens nodig. Bij een rode build: open de stap Build unsigned iPhone app en kopieer de eerste error:-melding met wat regels eromheen voor herstel van het project.

3Installeer vanaf Windows

Gebruik AltStore Classic voor deze eigen IPA. Volg de actuele officiële Windows-handleiding voor de Apple-componenten, AltServer en het aanmelden met je Apple-account.

  1. Installeer de vereiste iTunes- en iCloud-componenten volgens de officiële handleiding. Installeer vervolgens AltServer voor Windows.
  2. Verbind je ontgrendelde iPhone via USB, vertrouw de pc en zet Wi-Fi-synchronisatie aan volgens de handleiding.
  3. Gebruik het AltServer-icoon bij de Windows-klok: Install AltStore → jouw iPhone. Meld je lokaal bij AltServer aan met je Apple-account.
  4. Vertrouw het profiel op de iPhone bij Instellingen → Algemeen → VPN en apparaatbeheer. Zet ook Instellingen → Privacy en beveiliging → Ontwikkelaarsmodus aan en volg de herstartmelding.
  5. Zet ObjectScan-unsigned.ipa bijvoorbeeld via iCloud Drive of OneDrive in de app Bestanden op je iPhone.
  6. Laat AltServer draaien. Open AltStore op je iPhone en kies My Apps → +. Selecteer de IPA. AltStore ondertekent en installeert de app voor je toestel.

Je Apple-account hoort alleen in de officiële AltStore/AltServer-route. De scan-app en de GitHub-workflow vragen er niet om. Er is geen jailbreak nodig.

4Maak je eerste scan

  1. Kies eerst een mat object met zichtbare structuur, bijvoorbeeld een beeldje. Zet het stil neer in veel egaal licht.
  2. Open ObjectScan, geef cameratoegang en kies Nieuw object scannen.
  3. Neem het hele object in beeld, kies Object herkennen, pas het kader aan en kies Start scannen.
  4. Loop langzaam rond. Maak ook rondes van een hoger en lager standpunt. Gebruik Nog een ronde wanneer de app die optie toont. De app toont ook het maximale aantal foto’s voor je toestel.
  5. Vanaf twintig foto’s kun je Maak 3D-model kiezen. Volledige dekking met overlappende foto’s geeft een beter resultaat dan alleen het minimumaantal.
  6. Laat de app open tijdens de berekening. Kies daarna Exporteer 3D-model en sla het op in Bestanden of zet het op je pc.

De onderkant die op tafel staat is bij deze opnameroute niet zichtbaar. Glas, glanzend metaal en hele kleine details zijn lastiger. Controleer en herstel een model voordat je het voor een passende 3D-print gebruikt.

Gebruiken, bewaren en vernieuwen

Openen in Blender

Kies File → Import → Universal Scene Description en open je USDZ. Kies Import Textures: Packed om texturen mee te nemen. Vanuit Blender kun je exporteren naar OBJ of STL. Blender-documentatie

Opnieuw berekenen

Een volledig afgeronde opname blijft met bronfoto’s en checkpoints bewaard. Mislukt de berekening of sluit iOS de app af, kies dan bij die opname 3D-model berekenen. Een onvolledige opname kan in deze versie niet worden hervat; begin dan opnieuw.

Wekelijks vernieuwen

Start AltServer op de pc, zorg dat pc en iPhone elkaar via USB of hetzelfde netwerk kunnen bereiken en kies in AltStore My Apps → Refresh All. Doe dit vóór de termijn van zeven dagen. De huidige scans blijven daarbij behouden.

Je scans behouden

Exporteer belangrijke modellen apart. De app bewaart ook de bronfoto’s, die opslagruimte innemen. Een scan verwijderen vanuit de bibliotheek verwijdert na bevestiging ook die bronfoto’s. De app zelf verwijderen wist de lokale appgegevens.
